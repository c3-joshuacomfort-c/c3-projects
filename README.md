### Text Generator:

A mock data generation tool written in Rust. The tool takes in a given input file which should contain a single line of words separated by spaces. The default provided file is a lorem ipsum example. The generator will read in this file and create a new output file with a randomized order of words from the input. The user may specify how many words they would like to have in the output file.

Usage: ./text_generator input_file_name output_file_name
